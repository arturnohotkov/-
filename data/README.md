# Демонстраційні дані

Функція seed у core/model.mjs створює п’ять завершених циклів і один відкритий цикл умовного військового інституту. Вибірки є вигаданими груповими сумами. Жодного списку людей для їх побудови не потрібно. Навчальний захід травневого циклу показує, як виглядає завершений захід із повторним вимірюванням. Приклад CSV за листопад є у docs/example.csv.
